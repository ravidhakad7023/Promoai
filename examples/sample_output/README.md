# Sample output (synthetic)

These files show the **shape** of PromoAI's deliverables. Every value is invented for illustration:
the IDs, times, tiers and text placeholders do not come from any real screenplay or run, and none of
the numbers are results. Real outputs contain screenplay text and must stay private (see the main README).

- `ranked_promos.sample.json`: one promo with the main fields of `ranked_promos.json` (long lists and nested details trimmed).
- `ranked_promos.sample.csv`: the header and one row of `ranked_promos.csv`.
